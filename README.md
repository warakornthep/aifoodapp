# Foodsnap 📸🍜

แอปบันทึกอาหารด้วยรูปถ่าย — ถ่ายรูป → AI (OpenAI) บอกชื่อเมนู + แคลอรี่ → บันทึกและสรุปแคลอรี่ที่ได้รับวันนี้

## วิธีใช้
1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไร)
2. ไปที่ **ตั้งค่า** → ใส่ OpenAI API Key (ขอได้ที่ https://platform.openai.com/api-keys) → กด “ทดสอบคีย์”
3. กดปุ่มกล้องตรงกลาง → ถ่ายรูป/เลือกรูปอาหาร → รอ AI ประเมิน → ปรับแก้ถ้าต้องการ → **บันทึก**
4. หน้า **วันนี้** แสดงแคลอรี่รวม โปรตีน/คาร์บ/ไขมัน แยกตามมื้อ, หน้า **ประวัติ** ดูย้อนหลัง 7 วัน

ใช้บนมือถือได้โดยเปิดไฟล์ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ (หรือ host แบบ static) แล้ว “เพิ่มไปที่หน้าจอโฮม”

## เทคโนโลยี
- HTML/CSS/JavaScript ไฟล์เดียว ไม่มี build step
- เก็บข้อมูลใน `localStorage` (`foodapp.entries.v1`, `foodapp.settings.v1`)
- OpenAI Chat Completions (vision + structured output) โมเดลเริ่มต้น `gpt-4o-mini` เปลี่ยนได้ในตั้งค่า

## ความปลอดภัย
- API Key เก็บในเบราว์เซอร์เครื่องนี้ และถูกส่งตรงไปที่ api.openai.com เท่านั้น
- เหมาะกับใช้ส่วนตัว — ถ้าจะ deploy ให้คนอื่นใช้ ควรทำ backend proxy เพื่อซ่อนคีย์
- แนะนำให้ตั้งวงเงิน (usage limit) ให้คีย์ที่ใช้กับแอปนี้
- ค่าประมาณแคลอรี่จาก AI เป็นเพียงการประเมินคร่าวๆ ปรับแก้ตัวเลขได้ก่อนบันทึก
